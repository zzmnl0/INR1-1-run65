## 路线

1. 以 S1 确认的命令为根，追踪 Python 导入、动态加载、PowerShell/批处理调用、配置选项和运行时文件访问。
2. 初始检查入口包括 `main_fsia.py`、`plot_fsia.py`、`evaluate_giro_peak.py`；核心候选包括 `inr_modules/config_mdia.py`、`inr_modules/mdia/`、`inr_modules/data_managers/`、`isr_evaluation/` 和 `traditional_static_etkf/`。实际范围由 S1/S2 证据确定。
3. 对模型、训练器、损失、数据读取、IRI 背景、评估、绘图分别列调用方、输入输出、配置开关、测试与外部依赖。
4. 检查序列化依赖：历史检查点可能保存模块路径、状态键或配置字段。改名、移动类和删除兼容字段前，核对加载方式及保留权重的需求。
5. 搜索文档命令、手动工作流和跨项目调用。静态搜索无调用仅为线索，仍需与保留工作流对照。
6. 分类到文件和必要的函数/分支级别；未明确归属内容继续保留，不把整个目录按名称批量移除。
7. 系统核查零权重及False开关：比较默认、入口覆盖、校准和恢复后的主/S6配置，追踪计算及结果消费者，区分完全不执行、计算后乘0、共享用途和控制值。交付 [零值分支清单](records/zero_config_review.md)，关联C11–C14。

## 处置清单

实施时生成 `records/scope_inventory.md`，字段为：路径/符号、职责、调用者、所属工作流、配置条件、序列化影响、证据、处置、验证项。

| 处置 | 判定标准 |
| --- | --- |
| 保留 | 当前模型或论文复现所需，含必要比较工具及检查点兼容层 |
| 简化 | 功能需保留，但内部存在经证明的重复或无效逻辑 |
| 归档后移出 | 已被替代、与保留链路无关，且历史用途可追溯 |
| 待确认 | 身份、共享用途或行为影响尚不清楚 |
