## 备份路线

1. 检查磁盘空间、目标目录权限、活动写入进程、符号链接和目录联接。记录快照范围；不跟随联接递归复制大型外部数据。
2. 保存当前项目全部代码和配置（含未追踪及必要的被忽略源码）、运行脚本、依赖版本、Git 提交及工作区差异、文档和已确认的历史运行证据。外部必需代码单独映射记录。
3. 数据、检查点与大型产物原位保留，建立绝对路径、大小和 SHA-256 清单；区分“已复制备份”与“仅登记且原位保留”。会被后续步骤覆盖的文件必须先独立复制。
4. 使用同级时间戳目录保存快照，生成逐文件哈希并与源文件核对。若备份期间源文件变化，记录并重做受影响文件的快照核对。
5. 在独立临时目录抽检恢复，检查路径和文件完整性。备份不包含凭据；私有代码仍按现有权限保管。

## 行为基线路线

按照 [S5 验证矩阵](05_VALIDATION_HANDOVER.md#验证矩阵) 固定权重、输入样例、随机种子、设备、dtype、软件版本及输出位置，记录清理前检查点加载、前向、无观测回退和必要评估结果。

浮点比较标准在清理前根据运算确定性确定；同环境确定性路径优先逐值一致。确需容差时记录理由与阈值，不根据清理后的误差倒推阈值。已有失败记录保留并注明是否先于清理存在。
